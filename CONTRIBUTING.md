# Guía de Contribución - Triage Frontend

Agradecemos las contribuciones al proyecto institucional.

## Estándares de Trabajo
1. Cree una rama descriptiva: `feature/nombre-mejora` o `fix/descripcion-bug`.
2. Respete la guía de estilo de código: componentes funcionales y hooks limpios.
3. Asegure que `npm run build` ejecute sin advertencias críticas antes de abrir un Pull Request.
