# Exportación de Reportes de Turno

Mecanismo para generación de informes asistenciales al cierre de guardia:

- **Formato CSV**: Exporta el censo completo de pacientes atendidos, tiempos de espera y niveles asignados.
- **Formato Impresión / PDF**: Estilo CSS `@media print` optimizado para impresión en blanco y negro sin fondos oscuros.
