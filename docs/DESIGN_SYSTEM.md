# Sistema de Diseño Clínico

La interfaz utiliza una paleta cromática inspirada en directrices internacionales de urgencias médicas para reducir la fatiga visual.

## Niveles Manchester y Códigos Hexadecimales
- **Nivel I (Reanimación)**: `#dc2626` (Rojo Intenso) - Atención inmediata (0 min)
- **Nivel II (Emergencia)**: `#ea580c` (Naranja) - Máximo 10-15 min
- **Nivel III (Urgencia)**: `#ca8a04` (Amarillo) - Máximo 60 min
- **Nivel IV (Prioritario)**: `#16a34a` (Verde) - Máximo 120 min
- **Nivel V (No Urgente)**: `#2563eb` (Azul) - Máximo 240 min

## Tipografía
Fuentes Sans-Serif de alta legibilidad (`Inter`, `system-ui`) optimizadas para pantallas médicas.
