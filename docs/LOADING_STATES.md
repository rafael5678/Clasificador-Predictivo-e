# Gestión de Estados Asíncronos y Carga

Para evitar pantallas congeladas durante consultas al backend:

- **Skeleton Screens**: Marcadores de posición animados mientras se descarga la cola de pacientes.
- **Spinners de Botón**: Deshabilitan el botón de "Evaluar" para prevenir dobles registros por clic repetido.
- **Notificaciones Toast**: Mensajes no intrusivos en la esquina superior derecha informando el éxito de la operación.
