# Protocolo de Alertas Visuales y Sonoras

En salas de urgencias de alto tráfico:

1. **Alerta Crítica (Nivel I - Reanimación)**: Señal de audio discreta y borde parpadeante en la cabecera del monitor.
2. **Alerta de Reevaluación**: Notificación visual amarilla cuando un paciente de Nivel III supera los 60 minutos de espera.
3. El audio se gestiona mediante la Web Audio API con posibilidad de silenciado por el operador.
