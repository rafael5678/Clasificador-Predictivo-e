# Estructura del Proyecto Frontend

```
├── public/                 # Recursos estáticos públicos
├── src/
│   ├── ml/                 # Algoritmos de inferencia y datasets locales
│   │   ├── dataset.js
│   │   └── modelo.js
│   ├── api.js              # Integración HTTP con Axios / Fetch
│   ├── App.jsx             # Componente raíz con pestañas y módulos
│   ├── main.jsx            # Punto de entrada de React
│   ├── styles.css          # Estilos globales y paleta Manchester
│   └── triage.js           # Utilidades y conversiones de unidades
├── index.html              # HTML base
├── package.json            # Metadatos y scripts
├── vercel.json             # Enrutamiento para SPA en Vercel
└── vite.config.js          # Configuración de Vite
```
