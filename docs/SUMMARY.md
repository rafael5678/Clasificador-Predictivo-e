# Resumen Técnico Consolidado - Frontend

- **Tecnologías**: React 18, Vite, Vanilla CSS con arquitectura modular.
- **Algoritmo**: Clasificador predictivo basado en matrices Manchester.
- **Integración**: Conexión REST con API Spring Boot en Render Cloud.
- **Despliegue**: SPA alojada en Vercel con rewrites automáticos.
