# Atajos de Teclado para Personal de Enfermería

Para acelerar el registro en momentos de saturación de sala:

- `Alt + N`: Abrir nuevo formulario de admisión.
- `Alt + M`: Enfocar monitor dinámico de espera.
- `Alt + G`: Guardar y procesar evaluación actual.
- `Tab` / `Shift+Tab`: Navegación secuencial por campos de signos vitales sin usar el ratón.
