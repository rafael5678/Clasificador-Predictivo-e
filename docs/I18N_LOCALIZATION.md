# Internacionalización y Glosario Multilingüe

El frontend está estructurado para soportar múltiples idiomas:

- Términos médicos estandarizados basados en MeSH (Medical Subject Headings).
- Formato de fecha y hora localizado según zona horaria del hospital (`Intl.DateTimeFormat`).
- Soporte planificado para Español, Inglés y Portugués en centros de referencia internacional.
