# Guía del Simulador de Casos Clínicos

El frontend incluye un generador de escenarios de prueba para validación docente y formativa:

- **Caso Paro Cardiorrespiratorio**: Inconsciente, apnea, saturación nula -> Clasifica Nivel I.
- **Caso Dolor Torácico Opresivo**: Diaforesis, hipertensión, EVA 9 -> Clasifica Nivel II.
- **Caso Cólico Renal Moderado**: Constantes estables, dolor intenso -> Clasifica Nivel III.
- **Caso Cuadro Gripal Leve**: Afebril, parámetros normales -> Clasifica Nivel V.
