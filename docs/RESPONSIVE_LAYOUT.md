# Diseño Responsivo y Adaptabilidad

El layout clínico se adapta a múltiples dispositivos hospitalarios:

- **Monitores de Sala (1920x1080 o superior)**: Distribución en 3 columnas (Admisión, Monitor de Espera, Estadísticas).
- **Tablets Médicas (768px a 1024px)**: Pestañas colapsables con navegación inferior accesible con pulgar.
- **Estaciones de Enfermería**: Soporte optimizado para visualización de alta densidad de datos.
