# Inventario de Dependencias Frontend

- **React (`^18.x`)**: Librería fundamental para construcción de interfaces reactivas.
- **React DOM (`^18.x`)**: Renderizado en el árbol DOM del navegador.
- **Vite (`^5.x`)**: Herramienta de compilación, bundling y servidor de desarrollo instantáneo.
- **@vitejs/plugin-react**: Soporte oficial de React con Fast Refresh en Vite.
