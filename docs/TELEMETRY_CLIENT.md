# Métricas de Rendimiento en el Cliente (Web Vitals)

Monitoreo de tiempos de respuesta del navegador:

- **LCP (Largest Contentful Paint)**: < 1.2 segundos para el monitor principal.
- **FID (First Input Delay)**: < 50 milisegundos en campos de entrada numérica.
- **CLS (Cumulative Layout Shift)**: 0.00, asegurando que los elementos de urgencias nunca salten de posición bruscamente.
