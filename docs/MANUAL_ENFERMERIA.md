# Guía Rápida de Operación Clínica

Pasos recomendados para el triaje diario:

1. Ingrese el número de identificación del paciente para verificar si ya está registrado.
2. Registre los signos vitales tomados con los monitores biomédicos.
3. Revise la sugerencia algorítmica de nivel Manchester.
4. Presione **Confirmar Triaje** para insertar al paciente en la cola dinámica de urgencias.
