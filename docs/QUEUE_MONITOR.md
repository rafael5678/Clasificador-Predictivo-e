# Monitor Dinámico de Sala de Urgencias

La vista de Monitor permite a médicos y coordinadores visualizar en tiempo real:

1. **Pacientes en Espera**: Ordenados por score de criticidad decreciente.
2. **Tiempo Transcurrido**: Cronómetro en minutos desde la hora de admisión.
3. **Alertas por Demora**: Indicador que parpadea cuando el tiempo de espera supera el límite del nivel asignado.
4. **Botón de Reevaluación Rápida**: Modal para registrar nuevos signos si el paciente presenta descompensación.
