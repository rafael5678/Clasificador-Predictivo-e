# Componentes Modales de Confirmación

La interfaz incorpora ventanas modales accesibles para acciones críticas:

- **Confirmación de Egreso**: Requiere selección del destino del paciente (Observación, Hospitalización, Alta médica).
- **Modal de Reevaluación**: Despliega los valores basales anteriores para permitir comparaciones inmediatas de signos vitales.
- Cierre mediante tecla `Escape` o clic en fondo atenuado.
