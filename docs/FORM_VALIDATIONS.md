# Reglas de Validación de Entrada

Para proteger la integridad de los datos, el formulario de ingreso aplica validaciones estrictas:

1. **Documento de Identidad**: Campo numérico no vacío, longitud mínima de 6 dígitos.
2. **Edad**: Rango válido entre 0 y 125 años.
3. **Frecuencia Cardíaca**: Rango permitido entre 20 y 260 lpm.
4. **Frecuencia Respiratoria**: Rango permitido entre 4 y 60 rpm.
5. **Temperatura**: Rango biológico aceptable entre 32.0°C y 43.5°C.
6. **Saturación O2**: Entre 50% y 100%.
